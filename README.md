# E-commerce Fraud Detection & Risk Analysis

## 📌 Project Objective
To analyze e-commerce transaction data to identify fraud risk using transaction behavior and security checks, supporting risk-based fraud prevention.

---

## 🧩 Business Problem
E-commerce platforms face increasing fraud losses while trying to avoid blocking genuine customers.
This project focuses on identifying high-risk transactions and applying security checks only where needed.

---

## 🛠 Tools Used
- Python
- Power BI
- Excel
- Statistics

---

## 🔍 Project Workflow
1. Data cleaning and validation
2. Exploratory Data Analysis (EDA)
3. Statistical hypothesis testing
4. Feature engineering and risk segmentation
5. Power BI dashboard creation

---

---

## 📈 Key Insights
- High-value or abnormal transactions have higher fraud risk
- Strong security checks significantly reduce fraud
- Selective use of 3-D Secure improves fraud prevention without hurting customer experience

---

## 💡 Business Impact
- Reduced fraud losses
- Lower false declines
- Risk-based fraud decision-making
